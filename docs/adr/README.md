# Architecture Decision Records

ADRs record decisions that materially constrain implementation or operations.

Statuses:

- `Proposed`
- `Accepted`
- `Superseded`
- `Deprecated`

Accepted ADRs are authoritative until superseded by a later accepted ADR.
